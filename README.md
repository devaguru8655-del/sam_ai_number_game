# Number Game

The computer picks a random number from 1 to 100 and you keep guessing. It tells you Too High, Too Low or Correct until you get it.

Built for the SAM AI Technologies Java Programming Internship.

## How to run

You need JDK 8 or newer.

```
javac NumberGame.java
java NumberGame
```

## Notes

- Invalid or out-of-range input is rejected without counting as an attempt.
- Shows the number of attempts at the end.
